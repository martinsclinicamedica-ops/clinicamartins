## Publicação no GitHub Pages

1. Faça backup do repositório atual.
2. Extraia este ZIP no computador.
3. No repositório do GitHub, substitua todos os arquivos pela nova versão.
4. Faça o commit na branch publicada pelo GitHub Pages.
5. Em **Settings → Pages**, confirme `main` e `/root`.
6. Aguarde a publicação e teste `https://clinicamartins.med.br/sitemap.xml`.
7. No Google Search Console, envie novamente o sitemap e solicite a indexação das novas páginas.

O arquivo `CNAME` mantém o domínio `clinicamartins.med.br`.


## Correção de caminhos

Esta versão usa caminhos relativos para imagens, CSS, JavaScript e páginas internas.
Ela pode ser testada em um servidor local e também funciona em um repositório de projeto do GitHub Pages.
Não abra as páginas internas diretamente pelo Explorador de Arquivos; use um servidor local ou o GitHub Pages.
